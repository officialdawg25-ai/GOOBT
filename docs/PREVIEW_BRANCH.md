# GOOBT development preview branch

This branch, `foundation/goobt-preview-current`, tracks the current GOOBT `main` snapshot for Cloudflare Pages preview deployment.

- Preview project: `goobt-commerce-dev`
- Production deployments are disabled at the Cloudflare Pages project level.
- Preview-only environment uses the GOOBT Supabase project URL and browser publishable key.
- A successful preview deployment does not imply visual/browser QA or production readiness.
- Keep this branch synchronized from `main` after CI checks; do not use it for production releases.
